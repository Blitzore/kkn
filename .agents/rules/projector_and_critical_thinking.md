# PEDOMAN KERJA: MEDIA VISUAL PROYEKTOR KELAS & CRITICAL THINKING

## 1. Lingkungan Penggunaan
- **Visual Display Proyektor:** Media ini diproyeksikan di depan ruang kelas SD oleh instruktur/fasilitator KKN.
- **Kertas Soal Fisik:** Siswa mengerjakan soal di lembar kertas soal yang dibagikan. Siswa tidak memegang gadget individual.
- **Interaksi:** Fasilitator mengoperasikan web di depan kelas untuk menguji dan memvisualisasikan algoritma yang dipecahkan siswa.

## 2. Tipografi & Hierarki Visual Proyektor
- **Aturan / Cara Main / Soal Tantangan WAJIB BESAR:**
  - Ukuran teks aturan misi, panduan sortir, instruksi tantangan harian harus besar (minimal 1rem - 1.15rem), tebal, kontras tinggi, dan terbaca jelas dari bangku belakang kelas.
- **Jangan Membesarkan Hal Non-Esensial:**
  - Jaga dekorasi, ikon hiasan, log console teknis, tombol sekunder tetap proporsional dan tidak mendominasi layar.

## 3. Filosofi Critical Thinking (Tanpa Bocoran / Spoon-Feeding)
- Dilarang memberikan petunjuk yang langsung membocorkan jawaban atau konstruksi koding teknis (misal: jangan menempelkan teks "(ELSE)" pada clue).
- Dilarang memberikan placeholder kode jawaban di kolom input.
- Dilarang menyediakan tombol auto-fill / shortcut bantuan cepat.
- Siswa harus menganalisis aturan di layar proyektor dan merumuskan jawaban sendiri di lembar soal.

## 4. Kebersihan Kode: Hapus Kode & File yang Tidak Terpakai
- Selalu hapus baris kode, fungsi, dan class CSS yang sudah tidak terpakai (no dead code).
- Hapus file sementara atau aset yang sudah tidak lagi digunakan (no orphan/unused files).
- Jaga repositori tetap rapi, efisien, dan bersih.
